# iPhone 连接九号车辆视频教程流程

> 教程对象：普通用户，不讲代码或协议实现。  
> 使用设备：iPhone（iOS 14 或更高版本）和本人名下的 Ninebot / Segway 车辆。  
> 使用应用：公开项目 `Segway-Ninebot BLE App` 的 iOS 版本，假定已安装完成。  
> 资料核对：2026-09-08。

## 视频定位

- 建议标题：`iPhone 如何连接九号车辆？扫描、配对和实时数据完整演示`
- 建议时长：4-6 分钟。
- 全程竖屏录制 iPhone，车辆确认键用另一台设备补拍特写。
- 只连接自己的车辆。车辆 SN、蓝牙地址、password、ident 和凭据二维码必须打码。
- 新配对可能改变车辆保存的连接凭据。已经在九号官方 App 配对的车辆，优先使用“Connect with password”。

## 开拍前准备

1. iPhone 打开“设置 → 蓝牙”。
2. 关闭九号官方 App 和其他可能连接车辆的 App，最好从后台划掉。
3. 车辆停稳并保持在 iPhone 附近。
4. 准备好已经安装的 `Segway-Ninebot BLE App`。
5. 如果准备使用旧凭据，提前把本人 iPhone 备份中的凭据制成二维码，并在电脑或另一台设备上显示。不要把二维码放在正在扫码的同一台 iPhone 上。
6. 录屏时打开“勿扰模式”，避免通知泄露个人信息。

## iPhone 实际操作步骤

### 推荐方式：使用已有 password 连接

适合已经通过九号官方 App 配对过、不想重新配对的车辆。

1. 在 iPhone 上打开 `Segway-Ninebot BLE App`。
2. 首次弹出蓝牙权限时选择允许。
3. 在首页点击扫描，等待车辆出现在列表中。
4. 核对名称后点击自己的车辆。
5. 选择 `Connect with password`。
6. 点击 `Scan setup QR`。
7. 首次弹出相机权限时选择允许。
8. 用 iPhone 扫描电脑或另一台设备上显示的本人车辆凭据二维码。
9. 确认 password 字段已自动填入；只查看实时数据时，ident 可以不提供。
10. 点击 `Connect`，保持 App 在前台等待。
11. 进入实时仪表并看到数据刷新后，连接完成。

### 备选方式：新配对

适合车辆没有可用旧凭据，且车主明确接受原有官方 App 配对可能受影响的情况。

1. 扫描并点击自己的车辆。
2. 选择 `New pairing`。
3. 看到车辆确认提示后，在规定时间内短按车辆实体确认键。
4. 不要长按，不要启动车辆，也不要反复点击 App。
5. 等待 App 自动完成配对并进入实时仪表。
6. 如果超时，先断开并关闭其他车辆 App，再从扫描开始重试一次。

视频中建议把这条路径标成“备选”，不要剪成默认推荐操作。

## 可选：从本人 iPhone 备份准备连接二维码

这一段适合作为单独章节或下一期视频。它需要电脑，iPhone 本身不能直接从普通界面查看这些值。

### 1. 创建未加密的本地备份

Mac：

1. 用数据线连接 iPhone，打开 Finder。
2. 在侧边栏选择 iPhone，进入“通用”。
3. 选择把 iPhone 数据备份到这台 Mac。
4. 不勾选“加密本地备份”，点击“立即备份”。

Windows：

1. 用数据线连接 iPhone，打开 Apple Devices 或 iTunes。
2. 选择 iPhone，选择把数据备份到本机。
3. 不勾选“加密本地备份”，开始备份。

如果公司策略或个人隐私要求必须加密备份，不要为了本教程关闭保护。公开工具说明针对未加密备份。

### 2. 找到九号 App 的凭据文件

公开文档给出的备份内文件为：

```text
7f/7fff5a30d7d67fe00bf012e2dc3a61f63c8661bd
```

它对应九号 App 的：

```text
Library/Preferences/com.ninebot.segway.plist
```

常见备份根目录：

- macOS：`~/Library/Application Support/MobileSync/Backup/`
- Windows iTunes：`%APPDATA%\Apple Computer\MobileSync\Backup\`
- Windows Apple Devices：`%USERPROFILE%\Apple\MobileSync\Backup\`

不同版本路径可能不同，以 Apple 软件显示的实际备份位置为准。

### 3. 只提取本人车辆对应的两个字段

- `{车辆SN}_decrypt`：必需的 session password。
- `{车辆SN}_ident`：车辆控制授权；只看实时数据时不需要。

不要在视频中展示真实字段值。password 和 ident 都是敏感凭据；包含它们的二维码也必须视同车辆钥匙。

### 4. 生成二维码

公开项目规定的二维码内容格式是：

```text
segway://credentials?sn=<车辆SN>&pwd=<32位十六进制password>&ident=<32位十六进制ident>
```

只读连接可以省略 `ident`：

```text
segway://credentials?sn=<车辆SN>&pwd=<32位十六进制password>
```

推荐使用公开协议仓库自带的 `tools/make_creds_qr.py` 生成，不要把真实凭据提交到在线二维码网站。生成后在电脑屏幕显示，供 iPhone 的 `Scan setup QR` 扫描。

## 常见问题

### 扫描不到车辆

- 检查 iPhone 蓝牙是否开启。
- 到“设置 → 隐私与安全性 → 蓝牙”确认 App 权限已开启。
- 彻底关闭九号官方 App 和其他车辆 App。
- 靠近车辆后重新扫描。

### 点车辆后连接超时

- 不要在系统蓝牙设置里手工连接。
- 退出当前连接，等待几秒后重新扫描。
- 保持 App 在前台，不要来回切换应用。

### 二维码无法识别

- 确认二维码完整、清晰，四周留有白边。
- password 必须转换为 32 位十六进制。
- 如果二维码包含 ident，它也必须是完整的 32 位十六进制；错误 ident 会导致整个二维码被拒绝。
- 不要用正在显示二维码的同一台 iPhone 扫码。

### 认证失败

- 检查二维码中的 SN 与当前车辆一致。
- 确认 `_decrypt` 来自同一辆车，而不是 `auth` 或其他字段。
- 如果官方 App 后来重新配对过，旧二维码可能已失效，需要从新的本人备份重新准备。

### 可以看数据，但控制按钮无效

只读连接只需要 password；开关电源、开座桶等操作还需要同一辆车的 ident。本教程不演示车辆控制，也不建议为了控制功能传播或共享 ident。
